# Портфолио проектов по проектированию ПЛИС

Здесь собраны мои отчеты по курсовым и лабораторным работам, выполненным на ПЛИС (Verilog, Xilinx Vivado).

## 📂 Список работ

### 1. Конвейерное процессорное ядро на Verilog
- **Описание:** Разработка процессорного ядра с 5-стадийным конвейером.
- **Что сделано:** Реализован конвейер (Fetch, Decode, Execute, Memory, Writeback), базовый набор из 10+ инструкций (арифметика, логика, пересылки). Добавлены механизмы разрешения конфликтов и обхода данных (forwarding unit).
- **Инструменты:** Verilog, Xilinx Vivado, ModelSim.
- **📄 Ссылка на отчет:** [Конвейерное процессорное ядро (PDF)](./конвеерное%20процессорное%20ядро.pdf)

### 2. Устройство генерации псевдослучайных чисел (Курсовая работа)
- **Описание:** Генератор на основе физических шумов с микрофона ADMP421, реализованный на плате Nexys A7.
- **Что сделано:** Разработана RTL-модель (модули `TOP.v`, `sp_anl.v`, `CORDIC`), проведена верификация и макетирование.
- **Инструменты:** Verilog, Xilinx Vivado, Python.
- **📄 Ссылка на отчет:** [Перейти в папку с курсовой работой](./генерация%20псевдослучайных%20чисел)

### 3. Система обработки команд (Лабораторная работа №5)
- **Описание:** Система, включающая анализатор, обработчик команд, генератор сообщений и системную шину.
- **Что сделано:** Спроектированы конечные автоматы (FSM), модули UART, ПЗУ, RAM, контроллер светодиодов. Проведено тестирование на ПЛИС.
- **Инструменты:** Verilog, Xilinx Vivado, ISim.
- **📄 Ссылка на отчет:** [Система обработки команд (PDF)](./система%20обработки%20команд.pdf)

### 4. Изучение принципов широтно-импульсной модуляции (Лабораторная работа №1)
- **Описание:** Управление RGB-светодиодом на отладочной плате Nexys A7 с реализацией плавных переходов цветов и регулировкой яркости/скорости.
- **Что сделано:** Разработана системная модель на C++. Реализованы модули ШИМ (`PWM_FSM`), фильтр дребезга кнопок (`debounce`), синхронизатор и драйвер семисегментного индикатора. Использован алгоритм CORDIC для генерации синусоидальных сигналов.
- **Инструменты:** Verilog, Xilinx Vivado, C++.
- **📄 Ссылка на отчет:** [Изучение принципов ШИМ (PDF)](./изучение%20принципов%20ШИМ.pdf)
